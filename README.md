# Pet Breed Explorer

Pet Breed Explorer is a web application for browsing dog and cat breeds.

The app uses The Dog API and The Cat API to display breed information and images.

## Live Demo

[View the application](https://pet-breed-explorer-derpnrd55-jagnajs-projects.vercel.app/)

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- The Dog API
- The Cat API

## Features

- Browse dog and cat breeds
- View breed images and names
- View detailed information about a selected breed
