# Pet Breed Explorer

Pet Breed Explorer is a Next.js application for browsing dog and cat breeds and viewing detailed breed information.

The app uses The Dog API and The Cat API to load breed data and images.

## Live Demo

[View the application](https://pet-breed-explorer-silk.vercel.app/)

## Tech Stack

- Next.js
- React
- TypeScript
- Redux Toolkit
- Tailwind CSS
- The Dog API
- The Cat API

## Features

- Browse dog and cat breeds
- View breed images and names
- View detailed information about a selected breed
